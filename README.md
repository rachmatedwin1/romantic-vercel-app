# 💕 Romantic Messages Vercel App

A simple Next.js app that displays random romantic messages, perfect for sharing love and positivity!

## Features
- Romantic message generator
- Beautiful design
- Ready to deploy on Vercel

## Running Locally

```bash
npm install
npm run dev
```

## Deploying to Vercel

1. Push this repository to GitHub.
2. Connect your repo on [Vercel](https://vercel.com/import).
3. Deploy and share your love!
